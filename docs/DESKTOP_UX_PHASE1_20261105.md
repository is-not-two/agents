# 桌面 Web 第一批

范围：笔记/收藏未保存保护、桌面求职摘要与待跟进、Agent 提问前置。没有手机布局改造、数据库迁移或权限变更。

`python scripts/ci_gate.py --desktop-ui` 执行原有离线门禁及隔离桌面浏览器交互检查，需要已安装 Node/Playwright。浏览器使用临时配置和合成 HTTP，不连接真实数据库、供应商或保存的用户会话。Linux 可用 Playwright 自带 Chromium，或以 PLAYWRIGHT_EXECUTABLE_PATH 显式指定已安装浏览器。

覆盖 Esc/取消/路由/离站保护、保存中关闭、失败保留、成功无误报、409冲突、明确放弃、正文不进浏览器存储；20条岗位下摘要折叠、列表/详情首屏、待跟进筛选、统计展开状态；Agent主操作首屏、高级设置可达、原始运行请求保持及失败保留输入。

本批未实现：服务端草稿暂存、手机专属界面、规划执行列表、统一收录、工作流模板向导。原生 PostgreSQL 恢复及真实模型质量不由本批浏览器模拟替代。
