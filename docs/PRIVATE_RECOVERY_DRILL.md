# 原生空目标恢复演练：执行与验收边界

## 当前已经验证、尚未验证

- 已验证：私密状态显式重试的本机真实浏览器场景；使用生成口令/密文的加密备份往返；
  损坏密文在进入目标事务和创建口令元数据前被拒绝。没有读取真实私密内容。
- 尚未验证：本批精确提交在真实 PostgreSQL 上的完整私密记录/历史恢复、重启后解锁、
  事务中断后重试。本机未发现原生 PostgreSQL 工具；现有部署 SSH 身份仅允许
  status/upload/deploy，不能据此调用任意 QA 命令。
- 不重设现有口令，不使用真实恢复码，不拿 8770/8771 的业务数据库作为恢复目标。

## 执行前绑定

| 参数 | 必须满足的约束 |
|---|---|
| SOURCE | 本批精确提交的干净导出；保留 MiMo 修复和私密口令遗失警告 |
| QA_OS_USER | 专用非 root QA 身份；不是现有生产或预览 app 身份 |
| QA_OUTPUT | 新的隔离证据目录；不包含业务口令、数据库密码或正文 |
| QA_WORK_ROOT | 独立可写工作根；不是现有集群、生产/预览 data 或 socket 目录 |
| PostgreSQL | 原生 PostgreSQL 16 + pgvector；由已安装的受控工具提供 |
| 进程隔离 | 私有网络命名空间；业务配置、数据和 socket 不可见 |

未知身份/路径须由现有原生 QA 通道核实；不可用部署密钥尝试绕过白名单。

## 运行入口

只在满足上表条件的 Linux QA 执行环境中运行现有协调器；SOURCE 等为绑定参数槽，
不是可直接粘贴的生产路径：

```sh
python scripts/native_qa.py \
  --source SOURCE \
  --output QA_OUTPUT \
  --work-root QA_WORK_ROOT \
  --expected-os-user QA_OS_USER \
  --timeout 1800
```

协调器负责创建有身份标记的新集群并执行回归，不能用手动设置
SHILIE_QA_RUN_ID 等环境变量伪造所有权；不单独对现有库执行恢复 CLI。
新预检测试必须进入该次全套 pytest。

## 必须观察到的验收矩阵

| 场景 | 具体断言 |
|---|---|
| 私密正常往返 | 两条合成私密记录、四个历史版本、一个软删除；公共哨兵和全部历史不变 |
| Web 解锁 | 原合成口令可解锁、错误口令拒绝、重启后需重新认证 |
| 非空目标/ID 冲突/不同元数据 | 全部拒绝，不覆盖原数据或校验文件 |
| DB 事务失败 | 没有部分记录提交；同一备份能安全重试，不误删元数据 |
| 文件发布失败 | 无半个备份包，不覆盖已有文件 |
| 损坏历史密文 | 写库与写元数据前拒绝，而不是恢复后才发现无法读取 |
| 原生 pg_dump/pg_restore | 完整来源/目标身份、快照、哈希、空目标和事务失败断言全部通过 |
