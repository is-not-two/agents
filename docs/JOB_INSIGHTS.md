# 岗位证据对照与求职周报

## 岗位分析不是能力评分

求职记录中打开“查看岗位证据对照”，或工作台选择“岗位证据对照”。先维护真实技能、实际证据/来源，以及需人工核对的学历、经验、到岗、语言等事实。

- 原文提取每条保留精确 JD 引用及字符区间；优先/明确不要求与普通提及分开，不输出录用概率。
- 自填证据只显示“已提供，待核实”；仅声明技能与没有资料分开。**资料未提供不等于不会**，不把缺关键词变成能力缺陷。
- 硬条件单独列出对应个人事实，但不自动判断资格是否满足。规则词表有覆盖边界，完整 JD 始终可读。
- 原始 JD 为空时不生成结论；岗位、资料、规则/实现版本改变后，冻结分析显示过期，不能直接用过期候选写卡。
- 选择缺证据项后明确确认，才建立 JD 来源复习卡；重复确认复用稳定 ID。它是你选择的复习主题，不是系统认定你不会。

资料存 `data/local/job-profile.json`，保留既定“不进业务数据库”边界；使用内容版本、跨进程锁及原子替换，409 保留表单，损坏文件不自动当空文件覆盖。合法的旧版纯 JSON 只在明确保存时升级封装。

分析结果与运行意图在 `data/local/job-analyses/`、`job-analysis-runs/` 留档；它们和个人资料不进入公共工作区导出或源码发布包。**这些文件不是加密保险库，请用受限账号/磁盘权限和单独私密备份保护**，恢复时保留文件内容与关联版本。不要在资料中填写任何密码、令牌或供应商密钥，也不读取/搬运 `E:\resume` 原文件。

## 离线规则与模型增强

默认规则模式完全不依赖模型或网络，词表与限制在 `config/jobs.yaml`。模型增强只有点击明确确认才外发 JD 与个人证据；API 也要求确认文本，不是“配置好模型后自动发送”。重复相同意图复用已保存结果，明确重新调用使用新的稳定请求标识，并提示可能重复费用。

模型端点只接受 HTTPS；HTTP 仅允许本机回环调试。请求不跟随重定向，不自动重试，不返回供应商错误正文或密钥。条目必须通过结构/引用校验，模型不能填写个人证据或资格结论，也不能通过遗漏削弱规则已提取的条件。失败、超限或无连接保留规则版并标明原因。

意图先落 `running`，再外发；进程中断后同一意图不会盲目重复调用。`running` 表示结果未记账/未知，不冒充完成；需核对后明确发起新调用。模型返回合法 JSON 不证明理解正确，真实 JD 人工验收仍需完成。

## 周报口径

工作台 → 求职周报。选择某周任意日期，服务端按配置固定 UTC 偏移计算周一零点至下周一零点。查看是只读的；“生成并保存纯统计周报”才冻结文件，可下载 Markdown、确认加入每周通知队列。

- 本周投递按 `applied_at`；面试复盘按 `interviewed_at`；复习按实际 `reviewed_at`；未来事件不提前计入。
- 投递组累计进面率：本周投递的有效记录中，截至生成时有真实面试复盘的比例；这不是当周新增面试数，也不是历史周末状态快照。分母为零时是 null/暂不计算，不编造 0%。
- 管道分布、待跟进/待复习为当前值；归档记录不计入统计。相同问题在同一复盘只计一次。
- 规划完成按版本中的 done 翻转计事件，包括显式恢复；不是独立任务数，新建已完成节点不算新增产出。
- 已保存周报与当前统计分开。数据、口径、实现或时区变化会使冻结结果过期，不静默覆盖；重新生成是明确动作。

模型周报只接收统计指标，最多排序三个真实关注项，不能自由生成数字或改写统计；挂掉保留纯统计。不会发送技能资料、面试全文或私密日记给模型。模型调用仍需逐次确认，结果未知时不自动重试。

周报留档在 `data/local/weekly-reports/`，每次意图在 `weekly-report-runs/`。每周通知操作 ID 稳定、与每日摘要分开；入队不是已发送，后续仍受通知中心状态和配置限制。

## CLI 与权限

```sh
python scripts/weekly_war_report.py --day 2026-10-28
python scripts/weekly_war_report.py --day 2026-10-28 --save
python scripts/weekly_war_report.py --save --enqueue
```

默认只读、纯统计，无模型、无 SMTP 外发、无表结构初始化。cron 是待管理员审核的模板，不自动继承 systemd 环境、不包含秘密，也未安装到生产。

## 验证与尚未完成的验收

纯规则测试含十份**合成** JD、词边界/否定/精确引用、证据与硬条件、伪造模型引用拒绝、私密 JSON 损坏/CAS。模型协议测试只对回环 HTTP fixture，包括错误正文/重定向/重复请求；不是实际供应商质量验证。周报用拥有随机身份的新建 QA PostgreSQL 验证跨周、空分母、同一复盘去重、规划版本事件和失效降级。
