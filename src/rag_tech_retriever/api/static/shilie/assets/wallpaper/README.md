# 首页动态壁纸素材（待提供）

把用户提供的图片和可选视频放进本目录，然后在 `home-wallpaper.js` 的 `WALLPAPER_ASSETS` 填写：

- `image`：以 `/static/shilie/assets/wallpaper/` 开头的本地图片路径，如 `home.webp`。图片是必需的静态降级帧；未设置或加载失败时不请求视频，也不显示壁纸层。
- `video`：同目录的可选静音循环视频，如 `home.mp4` 或 `home.webm`；留空则桌面仅对静态图做轻微移动。

桌面播放静音视频；手机、低资源设备和系统要求减少动画时仅展示静态图。离开首页或页面进入后台时停止播放。系统检测能力有限，低配置判定不能覆盖所有设备。素材不会由系统自动下载，实际文件大小、清晰度、版权及编码兼容性需用户提供并验证。
