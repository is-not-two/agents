# 小程序语音识别接口协议（chatSTT）

> 面向小程序开发者的对接文档。本接口已接入火山引擎豆包录音文件识别（标准版）真实服务，不再返回占位错误。

## 1. 接口概述

小程序上传录音文件得到音频 URL 后，调用本接口将音频转为文字，返回识别文本与音频时长。

| 项 | 说明 |
| --- | --- |
| 请求地址 | `POST /api/lianlian/chatSTT` |
| 请求方式 | POST，`application/x-www-form-urlencoded` |
| 鉴权 | 无（与同应用其他业务接口一致） |

## 2. 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `audio` | string | 是 | 音频的完整 URL（`http(s)://` 开头），由小程序先上传后获得 |

### 音频要求

- 支持格式：`wav`、`mp3`、`ogg`、`spx`、`amr`、`aac`、`m4a`（未带扩展名时默认按 `mp3` 处理）
- 服务端直接根据 URL 下载音频进行识别，请确保该 URL 可被公网下载、无鉴权限制

## 3. 成功响应

HTTP 200：

```json
{
  "code": 1,
  "show": 0,
  "msg": "success",
  "data": {
    "message": "这下好了好了好了，这下坏了坏了。坏了，这下好了。",
    "audio_duration": 15
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | `1` 表示成功 |
| `data.message` | string | 识别出的文本（已做数字归一化、标点补全） |
| `data.audio_duration` | int | 音频时长，单位秒 |

## 4. 失败响应

HTTP 200：

```json
{
  "code": 0,
  "show": 0,
  "msg": "未检测到有效人声",
  "data": []
}
```

### 错误信息对照（以 `msg` 为准）

| `msg` | 含义 | 建议处理 |
| --- | --- | --- |
| `缺少参数` | 未传 `audio` | 检查请求参数 |
| `缺少音频地址` / `音频地址无效` | `audio` 为空或非 `http(s)://` 链接 | 上传后回传完整 URL |
| `语音识别服务未配置` | 服务端未配置识别凭证 | 联系后端（正常情况下不会出现） |
| `识别服务不可用（上游 HTTP xxx）` | 识别服务端异常（5xx 或网络超时） | 提示用户稍后重试 |
| `语音识别服务未开通或凭证无识别权限` | 凭证无效或无识别权限 | 联系后端核查开通/凭证 |
| `音频无法读取：xxx` | URL 下载失败或音频解码失败 | 提示用户重新录制/上传 |
| `未检测到有效人声` | 音频可识别但无有效语音内容 | 提示用户重新录制清晰语音 |
| `语音识别超时，请稍后重试` | 服务端 30s 内未返回识别结果 | 提示用户稍后重试 |
| `语音识别失败：xxx` | 其他识别失败 | 按实际信息提示 |

## 5. 对接建议

- 成功时优先展示 `data.message`；失败时以 `msg` 作为用户可见提示即可
- 录制时建议提示用户语速适中、环境安静，以提高识别准确率
- 音频过长时识别耗时增加，服务端最长等待约 30 秒，小程序侧可设置对应的超时提示
